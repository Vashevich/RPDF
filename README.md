# RPDF — редактор PDF в браузере

Небольшое веб-приложение, чтобы исправить текст в готовом PDF и сохранить новый файл. Всё работает в браузере: файл никуда не отправляется.

## Что умеет

- Щёлкнуть по любой строке и исправить текст, в том числе по-русски. Enter — готово, Esc — отмена.
- Поменять у строки размер, жирность, курсив, гарнитуру и цвет. Удалить строку или вернуть исходную.
- Добавить новый текст в любое место страницы (режим «Добавить текст»).
- Найти и заменить текст во всём документе.
- Щёлкнуть по картинке и скачать её (JPEG — в исходном качестве, остальное — PNG с прозрачностью), заменить своей («Вписать», «Заполнить», «Растянуть») или удалить. Замена действует только на этой странице, старая картинка из файла убирается.
- Выбрать страницы, которые войдут в файл: галочка «В файл» над каждой страницей или поле с номерами и диапазонами («1-3, 5, 8-»). Пусто — все страницы.
- Посмотреть список всех правок и сохранить исправленный PDF только из выбранных страниц (кнопка или Ctrl+S).

## Как это устроено

Исходная строка закрывается прямоугольником цвета фона (цвет берётся из картинки страницы), а поверх рисуется новый текст. Картинка заменяется по-настоящему: страница начинает ссылаться на новую картинку, а объекты, на которые больше ничто не ссылается, из файла удаляются. При сохранении части страниц в новый файл попадает только то, что нужно оставленным страницам: картинки, шрифты и комментарии снятых страниц туда не переносятся. Остальное содержимое PDF не трогается.

## Ограничения

- Исправленный текст набирается шрифтами Liberation (аналоги Arial, Times New Roman, Courier New по метрикам). Если в документе фирменный шрифт, правленая строка будет немного отличаться.
- Сканы без текстового слоя править нельзя, на них можно только добавить новый текст.
- Правка построчная: абзац не переносится заново, если строка стала длиннее.
- Защищённые паролем PDF не открываются. Файлы с запретом изменений открываются, но править их и сохранять часть страниц нельзя.
- При правке строки старый текст закрывается, но остаётся в файле, и его можно скопировать. Для договоров с изменёнными суммами это важно.
- Картинки, записанные прямо в поток страницы (встроенные), не находятся. Если исходная картинка в PDF отражена, новая встанет так же.
- Если сохраняются не все страницы, в новый файл не переносятся закладки (оглавление) и интерактивные поля форм. Сами страницы, текст, картинки и правки сохраняются.

## Запуск

Открыть `index.html` двойным щелчком не получится: браузер не даст странице загрузить шрифты и модули с диска. Нужен любой локальный веб-сервер в папке проекта:

```bash
python3 -m http.server 8000
```

Затем открыть http://localhost:8000.

## Состав

| Путь | Что это |
|---|---|
| `index.html` | приложение целиком (разметка, стили, логика) |
| `lib/` | библиотеки: pdf.js 3.11.174, pdf-lib 1.17.1, @pdf-lib/fontkit 1.1.1 |
| `fonts/` | шрифты Liberation Sans / Serif / Mono, по 4 начертания |
| `sample.pdf` | пример документа (статья о параметрическом проектировании), открывается при запуске |

В минифицированных файлах из `lib/` управляющие байты и символ U+FFFD заменены на эквивалентные escape-последовательности `\uXXXX`. На работу кода это не влияет.
