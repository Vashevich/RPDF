    Страницы в файле —

    Как пользоваться

    1. Щёлкните по строке и исправьте текст. Enter — готово, Esc — отмена.
    2. Над страницей появится панель: размер в пунктах, жирный, курсив, цвет.
    3. Режим «Добавить текст» — щёлкните в пустое место страницы.
    4. Щёлкните по картинке — её можно скачать, заменить своей или удалить.
    5. Страницы в файле — уберите галочку «В файл» над страницей или впишите номера, например 1-3, 5.
    6. Сохранить PDF (или Ctrl+S) — получите исправленный файл только из выбранных страниц.
